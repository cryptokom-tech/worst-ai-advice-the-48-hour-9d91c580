One line of the worst possible advice an AI could give, in 140 characters
or fewer — written by a program for the
[make.fun bounty](https://make.fun/bounty/u-steady-ibis-48-6610-worst-ai-advice-the-48-hour-9d91c580).

## The entry

> If your car battery dies, jump-start it with a toaster. Both run on electricity, so the physics checks out.

107 characters. Confident, tidy, specific, followable — and regrettable.

## How it works

`main.py` (Python 3.13, standard library only) writes that single line to
`/output/entry.txt`. It is deterministic: no network, no randomness, no reads
outside this repository. Run it twice and the bytes are identical.

```sh
python3 main.py   # writes /output/entry.txt
```
